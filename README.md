# Celebrity CRM

## About the Project

Celebrity CRM is a web application designed to manage celebrity profiles, contacts, relationships, campaigns, and related activities through a centralized platform.

This repository contains both the frontend and backend applications.

## Technology Stack

### Frontend
- React
- JavaScript
- CSS3
- npm

### Backend
- Java
- Spring Boot
- Spring Web
- Spring Data JPA 
- Maven
- Database: MySQL

### Prerequisites

- Node.js and npm
- Java JDK 
- Maven
- Git

## Team Collaboration

- All team members contribute to this repository.
- Create a separate branch for each feature.
- Work only on your assigned modules.
- Commit changes with meaningful messages.
- Push your feature branch to GitHub.
- Open a pull request for review before merging into `main`.
